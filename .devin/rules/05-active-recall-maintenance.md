# Rule 05 — Active Recall Maintenance

When architecture or important behavior changes:

- add new recall questions
- retire obsolete questions
- update answers
- update feature traces
- update integration relationships
- update important-file ranking
- update mastery notes

Documentation should teach the codebase, not simply describe it. Update `.anvaya/knowledge/24_ACTIVE_RECALL.md` and `25_UNKNOWN_QUESTIONS.md`.

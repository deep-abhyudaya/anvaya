# Rule 05 — SOC UI + Judge Experience

The UI must make the core proof obvious within seconds.

Primary narrative:
`ATTACK → MISS → GROUND TRUTH → BACKTRACK → RULE PROPOSED → RULE VALIDATED → REPLAY → CAUGHT`

Required views:
- incident overview
- evidence/timeline
- SentinelBacktracker replay
- BlastScope graph
- What-If counterfactuals
- ControlLedger audit trail
- model/rule metadata

Use real API results. Fake UI data is forbidden in production components.

Provide robust loading, empty, error, retry, and stale-data states.

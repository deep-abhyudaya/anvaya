# Rule 01 — Source Fidelity

The supplied ANVAYA presentation controls explicit product requirements.

## Required architecture
- Next.js 15 / App Router
- Tailwind + shadcn/ui
- Cytoscape.js / React Flow
- Recharts
- FastAPI
- PostgreSQL
- SQLModel
- Isolation Forest
- NetworkX
- Logistic Regression
- GPT function-calling layer with strict structured outputs
- React Query polling at 3–5s initially
- Vercel frontend + Railway/Fly.io backend

## Terminology
Preserve these names in the product:
- Alertness + Self-Enhancement
- SentinelBacktracker
- Counter-Attack / BlastScope
- Defense / What-If Watcher
- Overall Response / ControlLedger
- `detected → analyzed → simulated → explained → sealed`

## Evidence discipline
If the presentation does not specify a detail, do not present an invented detail as if it came from the source. Put conservative assumptions in `docs/ASSUMPTIONS.md`.
